# OPP — Open Program Protocol

> **Autonomy under contract. Only what’s on the program ships.**

**Product:** OPP (Open Program Protocol)  
**Category:** Portable program contract + Ship Receipt verification  
**Status:** Phase 2 in progress — P-050 + A-030 Done; P-060 / RT-010 Open (D16)  
**Pricing:** Community / self-host **$0** only — no paid SKU UI

## 1. Promise

OPP makes the Open Program contract portable: parse spendable backlog, evaluate Spend License, verify Ship Receipts — independent of any single coding-agent runtime.
